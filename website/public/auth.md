# coeditHTML auth.md

Guide for autonomous AI agents, orchestrators, and automated clients interacting with coeditHTML.

## Overview

coeditHTML provides instant hosting and real-time collaboration for single-file HTML artifacts generated by AI tools (dashboards, decks, reports, prototypes).

- **No account or pre-registration required**: Agents can upload and publish artifacts immediately without API keys or accounts.
- **Token-based authorization**: Each published artifact produces three distinct, unguessable capability tokens:
  - `viewToken`: Read-only access to view the artifact.
  - `suggestToken`: Permission to add sticky comments and suggestions.
  - `editToken`: Permission to edit text in place, upload revisions, configure passwords, and manage share links.

---

## Agent Registration & Upload Endpoint

### Direct Anonymous Upload
Agents provision new artifacts by sending a `POST` request directly to the artifacts API:

```http
POST https://app.coedithtml.com/api/artifacts
Content-Type: multipart/form-data
```

#### Form Fields
- `file` (required): Standalone HTML file (max 5MB).
- `password` (optional): Plaintext string to lock the artifact with password protection.
- `draft` (optional): Boolean (`"true"`/`"false"`). If `true`, saves the file without minting public share links.

#### Response (201 Created)
```json
{
  "artifactId": "art_01j9x...",
  "viewToken": "v_abc123...",
  "suggestToken": "s_def456...",
  "editToken": "e_ghi789...",
  "viewUrl": "https://app.coedithtml.com/s/v_abc123...",
  "suggestUrl": "https://app.coedithtml.com/s/s_def456...",
  "editUrl": "https://app.coedithtml.com/s/e_ghi789...",
  "published": true,
  "restoredComments": 0
}
```

## Supported Identity & Authorization Flows

coeditHTML supports multiple standard authentication and discovery profiles:

1. **Anonymous / Zero-Barrier Flow**
   - **Identity Type**: `anonymous`
   - **Credential Type**: `bearer_token`
   - **Endpoint**: `https://app.coedithtml.com/api/artifacts`
   - **Mechanism**: Immediate upload without credentials. Returns capability tokens for subsequent operations.

2. **Identity Assertion Flow**
   - **Identity Type**: `identity_assertion`
   - **Supported Assertions**:
     - `urn:ietf:params:oauth:token-type:id-jag`
     - `verified_email`
   - **Claim URI**: `https://app.coedithtml.com/api/artifacts`

3. **Session Cookie Flow (Browser & Agent)**
   - The initial upload response sets an `owner` session cookie. Clients presenting this cookie can list all their active artifacts via `GET https://app.coedithtml.com/api/my-artifacts`.

## Scopes & Permissions

| Scope | Description | Required Capability |
| :--- | :--- | :--- |
| `artifacts:create` | Upload and publish a new HTML artifact | None (Open access) |
| `artifacts:read` | Inspect metadata and view rendered HTML | `viewToken`, `suggestToken`, or `editToken` |
| `artifacts:edit` | Modify text, add comments, and upload revisions | `editToken` (or `suggestToken` for comments) |
| `artifacts:settings` | Update passwords and rotate share links | `editToken` |
| `artifacts:delete` | Revoke a share token or delete an artifact | `editToken` or owner session |

## API Endpoints Reference

### Get Artifact Details
```http
GET https://app.coedithtml.com/api/artifacts/{token}
Accept: application/json, text/markdown
```

### Upload New Revision
```http
POST https://app.coedithtml.com/api/artifacts/{editToken}/revisions
Content-Type: multipart/form-data
```

### Update Settings / Password
```http
PATCH https://app.coedithtml.com/api/artifacts/{editToken}/settings
Content-Type: application/json

{
  "password": "new-secure-password"
}
```

### Revoke Token
```http
DELETE https://app.coedithtml.com/api/artifacts/{token}
```

## Code Examples

### cURL
```bash
# Upload a generated HTML file
curl -X POST "https://app.coedithtml.com/api/artifacts" \
  -F "file=@./report.html"

# Inspect artifact details
curl -s "https://app.coedithtml.com/api/artifacts/v_abc123..." \
  -H "Accept: application/json"
```

### TypeScript / JavaScript
```typescript
import { readFileSync } from "node:fs";

async function publishHtmlReport(filePath: string) {
  const formData = new FormData();
  const htmlContent = readFileSync(filePath, "utf8");
  formData.append("file", new Blob([htmlContent], { type: "text/html" }), "report.html");

  const response = await fetch("https://app.coedithtml.com/api/artifacts", {
    method: "POST",
    body: formData,
  });

  if (!response.ok) {
    throw new Error(`Upload failed with status: ${response.status}`);
  }

  const data = await response.json();
  console.log("Edit URL:", data.editUrl);
  console.log("View URL:", data.viewUrl);
  return data;
}
```

### Python
```python
import requests

def upload_artifact(file_path: str) -> dict:
    url = "https://app.coedithtml.com/api/artifacts"
    with open(file_path, "rb") as f:
        files = {"file": (file_path, f, "text/html")}
        response = requests.post(url, files=files)
        response.raise_for_status()
        return response.json()

result = upload_artifact("dashboard.html")
print(f"Share link: {result['viewUrl']}")
```
